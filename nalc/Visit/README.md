# NALC Miao — Voices, Visits & Moments That Made History

A standalone timeline webpage for the NALC Miao visitors archive.

## Included
- Responsive NALC-inspired visual theme.
- SEO title, description, keywords, canonical URL and Open Graph metadata.
- Timeline entries currently supplied during the project:
  - 2022: 30 Nov, 18 Dec
  - 2023: 15 Jan, 14 Aug, 30 Sep, 30 Dec
  - 2024: 30 Jan, 4 Mar
  - 2026: 17 Feb
- Four adaptive image placeholders per visit.
- Client-side image preview: portrait/landscape images retain their proportions.
- Five blank handwritten-feedback records for the 30 Jan 2024 LBSNAA visit.
- Footer identity: NALC Miao / Sub Divisional Library Miao / miaolibrary.in.

## Important
The entries are a working project record based on the details supplied during the conversation. Historical social-media verification should be completed before publication. No photographs or handwritten feedback have been fabricated.

## Deployment
The page can be served as a static site. Rename `index.html` or change the file path as needed for the final route.


## Regeneration note
The navigation/header was matched to the live NALC page at `https://miaolibrary.in/nalc`, including the same logo path `Assets/images/logo.png`. The existing timeline content, photo upload/preview controls and feedback placeholders were preserved.

The visitors timeline now uses the NALC Miao visual system from `miaolibrary.in/nalc`: Inter Tight typography, the NALC palette, typography scale, glass navigation/cards, rounded geometry, hero treatment, spacing language, and responsive sizing. The timeline structure and its existing content/photo controls are retained.
