NALC Miao — Enhanced nalc.html

This is a redesigned drop-in nalc.html for miaolibrary.in.

Highlights:
- Keeps the main site's Inter Tight font, teal/blue/lime/pink palette and rounded visual language.
- Adds glassmorphism, blur, responsive cards, scroll reveal and a polished event carousel.
- Adds an A4 portrait PM Award certificate upload/preview area (browser-local preview only).
- Adds ongoing/recurring programme carousel cards without inventing event dates.
- Includes metadata, canonical URL, Open Graph/Twitter cards and JSON-LD.
- Includes explicit NALC Miao -> miaolibrary.in relationship and homepage backlinks.
- Uses the existing main-site image paths: assets/images/gallery01.jpg, gallery03.jpg, gallery06.jpg, gallery08.jpg, gallery10.jpg, gallery13.jpg.
- Includes an image from the official NALC Miao X channel as a remote image and links to @NalcMiao.

IMPORTANT IMAGE NOTE:
The main-site gallery images are referenced from the existing repository and are not duplicated here. Copy nalc.html into the same repository/folder structure so those existing assets resolve.

The official Facebook photo feed could not be reliably harvested as downloadable image files from the public web in this environment. The page therefore links to Facebook instead of copying unverified media. If you provide the exact official Facebook page URL or upload the Facebook photos, they can be added as local assets without changing the design.

No GitHub repository or live site was modified by this package.
